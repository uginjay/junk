# Фактчекинг веб-приложение

Простое веб-приложение для проверки фактов в тексте с использованием AI и поиска в интернете.

## Возможности

- Извлечение ключевых фактов из текста с помощью OpenAI API
- Поиск информации в интернете через SearchAPI.io
- Автоматическая проверка каждого факта
- Красивый современный интерфейс
- Отображение источников для каждого факта

## Требования

- Python 3.8+
- OpenAI API ключ
- SearchAPI.io API ключ

## Установка

1. Клонируйте репозиторий или скопируйте файлы

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

4. Добавьте свои API ключи в файл `.env`:
```
OPENAI_API_KEY=your_openai_api_key_here
SEARCHAPI_API_KEY=your_searchapi_io_key_here
```

### Как получить API ключи:

- **OpenAI API**: Зарегистрируйтесь на https://platform.openai.com/ и создайте API ключ
- **SearchAPI.io**: Зарегистрируйтесь на https://www.searchapi.io/ и получите бесплатный API ключ

## Запуск

```bash
python app.py
```

Приложение будет доступно по адресу: http://localhost:5000

## Использование

1. Откройте приложение в браузере
2. Вставьте текст, содержащий факты для проверки
3. Нажмите кнопку "Проверить факты"
4. Подождите, пока AI проанализирует текст и проверит факты
5. Изучите результаты с вердиктами для каждого факта:
   - ✅ **ВЕРНО** - факт подтвержден
   - ❌ **НЕВЕРНО** - факт опровергнут
   - ⚠️ **ТРЕБУЕТ УТОЧНЕНИЯ** - факт неоднозначен или требует дополнительной проверки

## Технологии

- **Backend**: Flask (Python)
- **Frontend**: HTML, CSS, JavaScript
- **AI**: OpenAI GPT-3.5-turbo
- **Поиск**: SearchAPI.io (Google Search)

## Прототип фактчекинга (Flask)

Минимальное веб‑приложение для извлечения проверяемых фактов из драфта, поиска подтверждений в Яндекс.XML и формирования отчёта с вердиктами на основе OpenAI.

### Быстрый старт

1) Установите зависимости:

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

2) Запустите сервер разработки:

```bash
python app.py
```

Откройте `http://localhost:5000` и введите:
- OpenAI API Key (берётся у пользователя)
- Yandex XML `user` и `key` (зарегистрируйте их в Яндекс.XML)
- Текст драфта

3) Прод: через gunicorn

```bash
gunicorn -w 2 -b 0.0.0.0:5000 app:app
```

### Примечания
- Ключи вводятся на странице и не сохраняются на сервере
- Используются модели OpenAI (`gpt-4o-mini`); при необходимости замените в `app.py`
- Парсинг поиска — через `https://yandex.ru/search/xml`
- Проект — прототип, без сложной обработки ошибок и квот
